# Cecil is crazy

The 2026 version of the code created for Team 5002's test tank drive robot.

By amathew4538 and cecilj08-ux.

## About

This code is a reformatted version of the OG 2025 version of [CecilsGoingCrazy](https://github.com/amathew4538/CecilsGoingCrazy).

This code includes many improvements and LOTS of extra hours.

## Features

The main features include:

- PhotonVision
- Shifting
- Auto-shifting
- (Bad) Odometry
- (Bad) PS4/Xbox controller support
- Gyroscope
- SysID
- 180° turn
- Java Docs
- Elastic
- AdvantageScope

The W.I.P. features are:

- Choreo
- Photon View in Elastic
